# 3Sixty API Server Native

This package provides a native Node.js web server integration for exposing API routes with consistent runtime behaviour. It uses the built-in Node.js HTTP and HTTPS servers with the find-my-way router, with Socket.IO attached to the same server for socket routes.

## Installation

```shell
npm install @3sixty/api-server-native
```
