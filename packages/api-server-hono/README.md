# 3Sixty API Server Hono

This package provides Hono web server integration for exposing API routes with consistent runtime behaviour. It builds on the Hono framework, served through the Node.js adapter, with Socket.IO attached to the same HTTP server for socket routes.

## Installation

```shell
npm install @3sixty/api-server-hono
```
